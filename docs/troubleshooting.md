# Troubleshooting

再発しそうなトラブルだけを、短く記録する。

## 日本語文字化け

**症状**  
`http://localhost:4321/` で日本語が文字化けして表示された。

**原因**  
HTMLレスポンスの `Content-Type` に UTF-8 の指定が不足していた。

**対策**  
`astro.config.mjs` の文字化け対策用 Vite 設定を維持する。

**再発防止**  
理由なくこのUTF-8設定を削除しない。
