# AI指示作成ルール

Cursorでは主にGrokを使用する。

ChatGPTがGrok向けの作業指示を書く場合は、以下を守る。

- Grokに高度な文脈補完を期待しない
- 目的を最初に明記する
- 作業内容を具体的に書く
- 対象ファイルを明記する
- 作業順序を明記する
- 禁止事項を明記する
- 1回の指示で作業を広げすぎない
- エラー時は、修正より先に原因調査を指示する
- commit / push の有無を必ず明記する
- 最後に「ここで停止」と明記する
- 指示文は短くするが、曖昧にはしない
- Grokに貼り付ける指示はコードブロックで出力する

このファイルを、このリポジトリにおけるAI向け作業指示の正本とする。
