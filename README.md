# にゅうた動物病院 飼い主向け薬剤情報サイト

## 目的

処方薬の作用、副反応、注意事項を飼い主が確認できるようにする。

## サイト構成

- 共通QRコードからサイトトップへアクセスする
- トップページ：薬剤名検索 ＋ 50音順一覧
- 薬剤名を選択すると詳細ページを表示する

## 公開

- GitHub Pages で公開予定
- 将来的に `medicine.nyuta-ahp.com` を使用予定

## データ

薬剤データの原本は Google スプレッドシート。
